# DreamyHook UI DataTools Awesome Components

A collection of beautiful, production-ready UI components built with DreamyHook's signature brand theme featuring warm golden colors (Marigold Yellow, Buttercup Yellow, and Coral).

## 🎨 Brand Theme

**Primary Colors:**
- Marigold Yellow (#FCBF49)
- Midnight Blue (#0A1128)
- Buttercup Yellow (#FFD23F)
- Coral (#FF6B4A)

**Typography:**
- Headings: Poppins
- Body: Inter

## 📦 Components

### Aurora Background
A stunning animated aurora background effect with DreamyHook branding.

- **File**: `aurora-background-dreamyhook.html`
- **Type**: Single HTML file (no dependencies)
- **Features**: Smooth 60s animation, responsive, accessible, GPU-accelerated
- **Documentation**: See [AURORA_DOCUMENTATION.md](./AURORA_DOCUMENTATION.md)

**Quick Start:**
```bash
# Open directly in browser
open aurora-background-dreamyhook.html

# Or serve with local server
python3 -m http.server 8000
```

## 🚀 Usage

Each component is designed to be:
- **Self-contained**: Single file with all dependencies inline
- **Production-ready**: Optimized for performance
- **Accessible**: WCAG compliant with reduced motion support
- **Responsive**: Mobile-first design
- **Customizable**: Easy to modify colors and content
