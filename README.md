# DreamyHook UI Datatools - Awesome Components

A collection of beautiful, accessible, and performant UI components for DreamyHook.

## Components

### Beams Background
An animated background component featuring flowing gradient beams with DreamyHook's signature Marigold Yellow, Buttercup Yellow, and Coral colors.

**Features:**
- Pure HTML/CSS/JavaScript (no dependencies)
- Smooth 60fps canvas animations
- Configurable intensity levels (subtle, medium, strong)
- Fully responsive design
- Accessibility-first with reduced motion support
- DreamyHook brand theme integration

**Files:**
- `dreamyhook-beams-background.html` - Ready-to-use implementation
- `MODIFIED_PROMPT_DREAMYHOOK_BEAMS.md` - Complete integration guide and documentation

**Quick Start:**
Simply open `dreamyhook-beams-background.html` in any modern browser to see the component in action.
