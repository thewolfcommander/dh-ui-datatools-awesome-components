# DreamyHook UI Data Tools - Awesome Components

A collection of beautiful, performant UI components built with vanilla HTML, CSS, and JavaScript, styled according to the DreamyHook brand theme.

## 🎨 Brand Theme

**DreamyHook** uses a warm, professional color palette:
- **Primary**: Marigold Yellow (#FCBF49) - Warm, golden brand color
- **Accent**: Buttercup Yellow (#FFD23F) - Bright, cheerful highlights
- **Secondary**: Midnight Blue (#0A1128) - Deep, sophisticated text
- **Coral**: #FF6B4A - Warm accent for CTAs
- **Typography**: Poppins (headings), Inter (body text)

## 📦 Components

### Hero Highlight Component
**File**: `hero-highlight-dreamyhook.html`

A stunning hero section with:
- Mouse-following dot pattern effect
- Animated text highlighting
- Responsive design
- Zero dependencies (except Google Fonts)
- ~11KB total size

[View Documentation](./COMPONENT-DOCUMENTATION.md)

**Features**:
- ✅ Pure vanilla JavaScript (no frameworks)
- ✅ Single file implementation
- ✅ Performance optimized (~60fps animations)
- ✅ Fully responsive (mobile-first)
- ✅ Accessible (WCAG 2.1 compliant)
- ✅ Cross-browser compatible

**Quick Start**:
```bash
# Clone the repository
git clone https://github.com/thewolfcommander/dh-ui-datatools-awesome-components.git

# Open the component in your browser
open hero-highlight-dreamyhook.html
```

## 🚀 Usage

All components are standalone HTML files that can be:
1. Opened directly in a browser
2. Integrated into existing projects
3. Customized via CSS variables
4. Extended with additional JavaScript

## 🎯 Philosophy

These components follow the **DreamyHook Design Principles**:
1. **Performance First**: Optimized for speed and efficiency
2. **Accessibility Matters**: WCAG 2.1 AA compliant
3. **Developer Friendly**: Clean, readable, well-documented code
4. **Brand Consistency**: Unified color palette and typography
5. **Zero Bloat**: No unnecessary dependencies

## 🛠️ Tech Stack

- HTML5
- CSS3 (with CSS Variables)
- Vanilla JavaScript (ES6+)
- Google Fonts (Inter, Poppins)
