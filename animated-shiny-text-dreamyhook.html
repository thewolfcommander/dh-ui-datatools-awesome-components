How to Use

This is a single-file HTML component using vanilla CSS and JavaScript. Simply copy the HTML structure and customize the text and colors as needed. 

<div class="shiny-badge">
    <span class="animated-shiny-text">
        ✨ Your Text Here
        <!-- Arrow Icon SVG -->
    </span>
</div>

Customization Options

Available CSS classes for different variants:

  • shiny-badge - Default light theme
  • shiny-badge-golden - Golden gradient background
  • shiny-badge-midnight - Midnight blue background
  • shiny-badge-coral - Coral gradient background

CSS Variables

Adjust the shimmer width by changing the CSS variable: 

:root {
    --shiny-width: 100px; /* Adjust for wider/narrower shimmer */
}
