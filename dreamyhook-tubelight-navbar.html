DreamyHook Tubelight Navbar

A beautiful, animated navigation component with a glowing tubelight effect. Built with vanilla HTML, CSS, and JavaScript.

About This Component

The Tubelight Navbar is a modern navigation component featuring a unique glowing indicator that follows the active navigation item. Inspired by neon tubelight aesthetics, it combines smooth animations with the DreamyHook brand theme colors.

Smooth Animations

Fluid transitions and spring-based animations for a delightful user experience.

Fully Responsive

Adapts seamlessly between desktop and mobile views with icon-only mode.

Brand Themed

Perfectly aligned with DreamyHook's Marigold Yellow and Midnight Blue palette.

Features & Specifications

  • ✨ Glowing Tubelight Effect: Multi-layered glow effects simulate a real neon tube
  • 🎨 DreamyHook Theme: Uses Marigold Yellow (#FCBF49) as primary accent color
  • 📱 Mobile Optimized: Switches to icon-only mode on smaller screens
  • 🔄 Smooth Transitions: Spring-based animations using cubic-bezier curves
  • 🎯 Active State Tracking: Automatically highlights the current section
  • 🌈 Glassmorphism Design: Backdrop blur and transparency for modern aesthetics

Implementation Guide

Getting Started

This component is built with pure HTML, CSS, and vanilla JavaScript - no dependencies required! Simply copy the code into a single HTML file and you're ready to go.

Key Components

  • HTML Structure: Semantic navigation with accessibility in mind
  • CSS Variables: DreamyHook theme colors defined in :root for easy customization
  • JavaScript: Smooth scroll behavior and active state management
  • Icons: Inline SVG icons from Lucide for perfect scaling

Customization

All colors are defined as CSS variables in the :root selector. Adjust the brand colors, spacing, or animations to match your specific needs. The component is fully modular and easy to modify.
