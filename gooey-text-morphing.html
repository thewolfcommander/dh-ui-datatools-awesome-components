About This Component

This is a gooey text morphing animation built with vanilla HTML, CSS, and JavaScript. It features smooth transitions between words using SVG filters and custom animations.

Features

  • Smooth morphing transitions between multiple text strings
  • Customizable morph and cooldown durations
  • Dynamic text updates - change words on the fly
  • Responsive design that adapts to all screen sizes
  • DreamyHook brand theme with Marigold Yellow and Midnight Blue
  • Pure vanilla JavaScript - no framework dependencies
  • SVG filter effects for the gooey morphing appearance
